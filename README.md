# Web Development Bootcamp

Collection of daily exercises, practice projects, and assignments from the Web Development Bootcamp.

## 📂 Repository Structure

- **[Day-1](./Day-1)**: Introduction to JavaScript fundamentals, variables, and initial assignments.
- **[Day-2](./Day-2)**: JavaScript exercises, arrays, objects, and console-based project (`project1.js`).
- **[Day-3](./Day-3)**: HTML & CSS layouts, responsive styling, and GitHub clone practice.
- **[Day-4](./Day-4)**: GitHub landing page clone with CSS styling.
- **[Day-5](./Day-5)**: Asynchronous JavaScript deep-dive, callbacks, and Event Loop demonstrations.
- **[Todo app](./Todo%20app)**: Full Todo backend application built with Express and MongoDB.

## 🚀 Getting Started

### Running Daily Exercises
To run individual JavaScript files:
```bash
node Day-1/index.js
node Day-2/project1.js
node Day-5/script.js
```

### Running the Todo App
```bash
cd "Todo app"
npm install
node main.js
```
